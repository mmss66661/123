# 工作日志 — 双臂控制调试记录

## 硬件平台

- MCU: STM32F407
- CAN1: 瓴控(LK)双电机 + 达妙(DM)四关节电机，1 Mbps
- CAN2: DJI 系列电机
- 遥控器: DBUS 协议，5 通道摇杆 + 2 开关

## 机械臂构型

### 瓴控(LK)双电机臂（差速腕部，CAN1）

两电机转轴平行、方向相反，通过差速实现 Roll/Pitch 解耦：

- 同向转 → 末端绕 Roll 轴旋转（无限位）
- 反向转 → 末端绕 Pitch 轴旋转（机械限位，通过编码器差值做软件限位）

Pitch 相对位置 `Δ = uint16_t(angle2 - angle1)`，过零自动处理。上限约 46200~47000，下限约 31936~32000。

### 达妙(DM)四关节臂（CAN1）

| 关节 | 构型 | 电机 ID | 反馈 ID | 限位 (rad) | 控制模式 |
|------|------|:-----:|:-----:|------------|----------|
| J0 | 底部 yaw | 0x13 | 0x03 | 0 ~ 2.58 | 位置速度 |
| J1 | 底部 pitch | 0x00 | 0x01 | 0 ~ 1.21 | MIT (kp=50, kd=0.3) |
| J2 | roll | 0x14 | 0x04 | 0 ~ 1.85 | 位置速度 |
| J3 | 末端 yaw | 0x15 | 0x05 | 无限位 | 位置速度 |

### 爪夹舵机（TIM1）

左臂 CH1 固定 2500 µs，右臂 CH3 由 dbus.ch[2] 控制 800~1700 µs。

## 典型问题排查

### 1. 瓴控电机 "extern 收不到数据"（CAN 总线）

**现象**：`LK_motor_1/2` 结构体始终为 0。

**根因**：
- 只发了一次 `0x88` 运行命令，回复不含状态数据，且被解析分支丢弃
- `0x141` 分支只更新 `LK_motor_1`，`0x142` 进入 default 被丢弃
- 未发送协议规定的 `0x9C` 状态查询命令

**修复**：接收同时处理 `0x141/0x142/0x143`，统一解析 `0x9C/A1/A2/A7/A8` 回复；发送函数清零未初始化数组；控制循环持续发送速度命令（回复自带位置反馈）。

### 2. Pitch 限位方向判断错误

**现象**：限位阈值与编码器差值方向不匹配。

**根因**：最初用普通线性区间思维处理环形编码器。上限有两种表达（46700~47000 或 65536-19300=46236），下限同理（31936~32000）。

**修复**：统一用 `uint16_t(angle2 - angle1)` 做环形相对角，上限保守取 43200，下限取 1500。正 Pitch 定义为增大 Δ（`motor1 = roll - pitch`, `motor2 = roll + pitch`），限位只禁止继续撞向限位的方向，反向退出始终允许。20 计数余量 + 近限位比例降速防止惯性越界。

### 3. DM 电机 ID 反复修正

**问题**：代码中电机 ID 和反馈 ID 多次与电机内部存储的实际 ID 不匹配，导致使能帧发到了错误的 CAN ID。

**教训**：DM 电机的 CAN ID 由上位机配置工具写入电机 Flash，代码中的 ID 只是发送时拼接的目标地址，两者必须一致。后续任何 ID 变更都应先确认电机侧实际配置。

### 4. J1 从位置速度切到 MIT 模式

**原因**：J1 作为底部 pitch 关节需要力控特性，MIT 模式同时提供位置闭环 + 力矩前馈。

**实现点**：
- 新增 `dm_float_to_uint` 量化函数和 `BSP_CAN1_DMMotorMitCmd`（8 字节 MIT 帧拼装）
- 变量化 kp/kd 常数，便于调参
- MIT 用绝对位置映射（摇杆回中保持位置），区别于位置速度模式的增量映射

### 5. 函数前向声明缺失导致编译失败

`dm_float_to_uint` 定义在 MIT 函数调用点之后，C++ 要求先声明后使用。添加了前向声明解决。

## 算法/结构备注

### 差速解耦公式

```
motor1_speed = roll - pitch   // LK motor 1
motor2_speed = roll + pitch   // LK motor 2
```

等比例限幅保持差速关系：若单侧超速，双侧同比缩放到 `MOTOR_MAX_SPEED`。

### 位置速度模式 vs MIT 模式选择

- **位置速度模式**：适合关节空间轨迹跟踪。电机内环做位置 PID + 速度前馈，外环只需发送目标位置和速度限制。
- **MIT 模式**：适合需要力控/阻抗控制或可变刚度的关节。kp 决定位置刚度，kd 提供阻尼，tau 做力矩前馈。摇杆映射到绝对位置，回中保持，阻抗特性由 kp/kd 调。

J1 用 MIT 是因为底部 pitch 需要软刚度防止碰撞硬限位；其他关节用位置速度模式保证轨迹精度。

### CAN 总线负载

10 ms 周期内发送 6 帧（2 LK + 1 MIT + 3 DM pos），每帧约 130 µs @ 1 Mbps，总线占用率约 8%，足够安全。

### 后续可优化方向

- J1 MIT 的 kp/kd 可根据末端负载实时调整（自适应阻抗）
- Pitch 限位可加入加速度前馈，进一步减小越界风险
- 可将 DM 电机反馈 ID 常量化，与发送 ID 统一管理，减少手工维护 switch-case 的错误
- 四关节 DM 臂可考虑加入运动学正逆解，从末端位姿反算各关节目标角
