# 六轴机械臂录制回放说明

## 遥控器操作

Xbox 手柄使用单击锁存方式：

- 单击 RB：六个达妙电机失能，擦除旧记录并录制六关节位置和夹爪状态，黄灯亮。
- 单击 LB：校验记录，使能电机，以 0.3 rad/s 回到录制起点，然后回放，红灯亮。
- 单击 START：立即停止、失能全部电机并擦除录制区，绿灯亮。
- A/B：分别闭合/打开夹爪，不需要配合 RB。

故障灯色：蓝色表示反馈超时/CAN 发送失败，紫色表示电机报码，青色表示 Flash
擦写失败，白色表示无有效记录或位置超限。可直接再次单击 RB 或 LB 重试。
黄色和红色只在电机任务确实进入对应状态后显示。

录制保存的是夹爪实际已下发的开/合状态。`s1 = 2` 时保持并记录上一次有效状态；返回录制起点期间夹爪保持当前状态，正式开始轨迹回放后才执行记录中的夹爪动作。

按钮只在按下沿触发，松开后工作状态继续保持。BACK 按钮未使用。状态切换滤波约 50 ms。
START 每次按下都会擦除 Flash sector 11；要回放刚录制的轨迹，应从录制状态直接单击
LB。若先按 START，本次轨迹会被删除，之后 LB 会因没有有效记录而进入白灯故障状态。

上电后先等待 2 秒再向达妙电机发送命令。上电默认停止；通信超过 100 ms 未收到正确帧时自动停止并失能，恢复后需要重新单击 RB 或 LB。

## Flash 布局

- MCU：STM32F407IGH6，内部 Flash 1 MB。
- 录制区：sector 11，`0x080E0000` 至 `0x080FFFFF`，共 128 KB。
- 固件链接区已缩小至前 896 KB，GCC linker script 和 IAR ICF 均已同步修改。
- 每个采样点保存六个电机的 16 位原始位置、夹爪状态及对齐保留字节，共 16 字节。
- 最大采样点数 8190；100 Hz 下最长约 81.9 秒。
- 记录包含版本、采样周期、样本数和 CRC32。记录头的 magic 最后写入，因此录制中途掉电不会把残缺数据当成有效轨迹。

下载固件时不要使用“整片擦除”，否则 sector 11 中已录制的轨迹也会被清除。

## 安全策略

- DBUS 超过 100 ms 未更新：立即失能并回到停止状态。
- 任一关节反馈超过 100 ms 未更新：立即失能。
- 达妙电机为一发一收模式；录制时逐台发送 `0x7FF/0xCC` 状态刷新请求并保存六帧新反馈，旧固件则回退到失能命令取反馈。
- 达妙反馈状态 `0`（失能）和 `1`（使能）均属正常，`8~E` 才按电机故障处理并立即失能。
- 录制和回放均检查 J0/J1/J2 软件限位及 J4/J5 差速限位。
- 回放前对整段数据执行 CRC、样本数、关节限位和相邻点跳变检查。
- 旧版不含夹爪状态的轨迹会因记录版本不同而拒绝回放，需要重新录制。
- 回起点采用软件斜坡；跟踪误差过大时暂停斜坡。
- 回放中跟踪误差过大时暂停时间轴，持续 3 秒仍不能追上则失能。
- 回放完成后保持末端位置；按 START 失能并停止。

## 调试变量

可在调试器中观察：

- `arm_control_state`
  - `0`：安全失能
  - `1`：手动控制
  - `2`：录制中
  - `3`：录制已停止或容量已满
  - `4`：返回录制起点
  - `5`：回放中
  - `6`：回放完成
  - `7`：故障锁定
- `arm_record_sample_count`：已写入的录制点数。
- `arm_playback_sample_index`：当前回放点序号。
- `arm_fault_code`
  - `0`：无故障
  - `1`：DBUS 超时
  - `2`：关节反馈超时
  - `3`：电机反馈错误码非零
  - `4`：Flash 擦除失败
  - `5`：Flash 写入或录制提交失败
  - `6`：Flash 中无有效记录或记录校验失败
  - `7`：CAN 发送连续失败
  - `8`：返回起点超时
  - `9`：回放跟踪超时
  - `10`：采样点超过软件安全限位
- `arm_remote_raw_mode`：锁存模式，`0` 停止、`1` 录制、`3` 回放。
- `arm_requested_mode`：滤波后的模式，按键后约 50 ms 应变为对应值。
- `arm_missing_feedback_mask`：J0~J5 缺失反馈位图（bit0~bit5）。
- `arm_motor_error_mask`：J0~J5 电机报码位图（bit0~bit5）。
- `arm_can_tx_failed_joint`：CAN 发送失败的关节序号，`-1` 表示无发送失败。
- `DM_feedback_master_id[0..5]`：J0~J5 实际反馈帧使用的 Master ID。

故障后可直接单击 RB 或 LB 发起新重试。只有遥控器和六关节反馈均正常时，系统才会进入录制或回放。

## 首次实机测试顺序

1. 将机械臂卸载或悬空，确保急停/断电触手可及。
2. 复位后等待至少 2 秒，确认绿灯亮且六轴失能。
3. 单击 RB，确认黄灯亮、`arm_control_state == 2`，再缓慢手动拖动一个很小的轨迹。
4. 把机械臂放在离录制起点很近的位置，直接单击 LB，先验证低速回起点。
5. 确认回起点和回放方向正确后，再逐步扩大轨迹范围。
6. 测试结束后单击 START，确认绿灯亮、全部电机失能且录制数据已清除。

内部 Flash sector 擦写寿命有限；进入新录制和每次单击 START 都会擦除 sector 11，
不应高频反复操作。
