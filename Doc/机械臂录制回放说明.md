# 六轴机械臂录制回放说明

## 遥控器操作

使用 DBUS 的 `s2` 三挡开关。遥控器物理顺序从上到下为 `1、3、2`：

- 顶部 `s2 = 1`：六个达妙电机失能，擦除旧记录并以 100 Hz 录制六关节位置和夹爪状态。
- 底部 `s2 = 2`：摇杆手动控制。每次从录制或回放切回该挡时，先用当前反馈同步目标，再使能电机，避免目标跳变。
- 中间 `s2 = 3`：校验记录，使能电机，以 0.3 rad/s 回到录制起点；六轴到位并稳定 300 ms 后，以最高 2 rad/s 回放关节和夹爪动作。

录制保存的是夹爪实际已下发的开/合状态。`s1 = 2` 时保持并记录上一次有效状态；返回录制起点期间夹爪保持当前状态，正式开始轨迹回放后才执行记录中的夹爪动作。

所有挡位都有稳定时间判定，其中回放挡必须停留约 600 ms 才会生效。从底部手动挡拨向顶部录制挡时，快速经过中间挡不会误触发回放。

上电后先等待 2 秒再向达妙电机发送命令。上电或 DBUS 掉线恢复后，必须先把 `s2` 拨到底部手动挡 `2`，之后才能进入录制或回放，防止上电时意外运动。

## Flash 布局

- MCU：STM32F407IGH6，内部 Flash 1 MB。
- 录制区：sector 11，`0x080E0000` 至 `0x080FFFFF`，共 128 KB。
- 固件链接区已缩小至前 896 KB，GCC linker script 和 IAR ICF 均已同步修改。
- 每个采样点保存六个电机的 16 位原始位置、夹爪状态及对齐保留字节，共 16 字节。
- 最大采样点数 8190；100 Hz 下最长约 81.9 秒。
- 记录包含版本、采样周期、样本数和 CRC32。记录头的 magic 最后写入，因此录制中途掉电不会把残缺数据当成有效轨迹。

下载固件时不要使用“整片擦除”，否则 sector 11 中已录制的轨迹也会被清除。

## 安全策略

- DBUS 超过 100 ms 未更新：立即失能，恢复后要求开关先回中位。
- 任一关节反馈超过 100 ms 未更新：立即失能。
- 达妙电机为一发一收模式；录制时每个采样周期都向六个失能电机发送请求，再保存六帧新的反馈。
- 达妙反馈状态 `0`（失能）和 `1`（使能）均属正常，`8~E` 才按电机故障处理并立即失能。
- 录制和回放均检查 J0/J1/J2 软件限位及 J4/J5 差速限位。
- 回放前对整段数据执行 CRC、样本数、关节限位和相邻点跳变检查。
- 旧版不含夹爪状态的轨迹会因记录版本不同而拒绝回放，需要重新录制。
- 回起点采用软件斜坡；跟踪误差过大时暂停斜坡。
- 回放中跟踪误差过大时暂停时间轴，持续 3 秒仍不能追上则失能。
- 回放完成且 `s2` 仍在 3 时保持末端位置；拨回中位后进入手动控制。

## 调试变量

可在调试器中观察：

- `arm_control_state`
  - `0`：安全失能
  - `1`：手动控制
  - `2`：录制中
  - `3`：录制已停止或容量已满
  - `4`：返回录制起点
  - `5`：回放中
  - `6`：回放完成
  - `7`：故障锁定
- `arm_record_sample_count`：已写入的录制点数。
- `arm_playback_sample_index`：当前回放点序号。
- `arm_fault_code`
  - `0`：无故障
  - `1`：DBUS 超时
  - `2`：关节反馈超时
  - `3`：电机反馈错误码非零
  - `4`：Flash 擦除失败
  - `5`：Flash 写入或录制提交失败
  - `6`：Flash 中无有效记录或记录校验失败
  - `7`：CAN 发送连续失败
  - `8`：返回起点超时
  - `9`：回放跟踪超时
  - `10`：采样点超过软件安全限位

故障后先将 `s2` 拨回中位。只有遥控器和六关节反馈均正常时，系统才会重新进入手动模式。

## 首次实机测试顺序

1. 将机械臂卸载或悬空，确保急停/断电触手可及。
2. 将 `s2` 放在底部 `2`，复位后等待至少 2 秒，确认没有使能/失能循环。
3. 确认 `arm_control_state == 1`，六轴只保持当前位置，没有明显跳动。
4. 拨到录制挡，确认六轴完全失能，再缓慢手动拖动一个很小的轨迹。
5. 拨回中位，确认记录点数大于零。
6. 把机械臂放在离录制起点很近的位置，再拨到回放挡，先验证低速回起点。
7. 确认回起点和回放方向正确后，再逐步扩大轨迹范围。

内部 Flash sector 擦写寿命有限，每次进入一次新的录制都会擦除 sector 11 一次；不应以高频自动循环方式反复开始录制。
